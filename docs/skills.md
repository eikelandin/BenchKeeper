# Skills

What each skill does, who starts it, when it runs and what it writes, so you can pick one without reading its `SKILL.md`. The tables come from each skill's front matter; CI fails when this page differs from it (`node .github/scripts/skills-doc.mjs` rewrites it).

## BenchKeeper's skills

The BenchKeeper plugin installs these nine in Claude Code and Codex at every level. A skill that "you" start never starts on its own.
